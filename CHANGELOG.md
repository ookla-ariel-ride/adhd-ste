# Changelog

`ADHD-STE.md` merges two upstream works. This file lists the rules and wording that come from neither of them, by version. [`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md) says which sections come from which source.

## Version 1.5.0, 2026-11-20

- Rule 1: the clarifying question asks for the target and the mechanism in one question.
- Exception 1: a long explanation or plan uses a light form of the language rules, and the sentence limits are maximums.
- Exception 6: act on stated access, and do not ask the reader to do the work.
- Rule 3: the reply to a social message is one warm sentence.
- Examples: the examples in rules 1, 3, 5, and 8 no longer repeat prompts of the eval harness. Versions 1.1.0 to 1.3.0 had examples that copied four eval prompts, so their scores on those cases overstate the effect of the rules.
- Shorter file: this list moved here from the attribution block, rule 9 and exception 4 are shorter, and two structure rules that repeated rules 1 and 10 are gone.
- New variant: `variants/ADHD-STE-lite.md` has the same shape rules and nine short language rules in place of the word, grammar, sentence, and structure sections. It has no verb list and no word limits. In the tests it scored the same as the full file for quality and for readability.

Version 1.4.0 was a draft and has no release. Its eval is in `results/RESULTS.md`.

## Version 1.3.0, 2026-11-19

- Rule 3: a natural reply to a social message.
- Rule 5: state from evidence only.
- Rule 8: no weaker check or control to make a test pass.

## Version 1.2.0, 2026-11-19

After the quality eval of version 1.1.0:

- Rule 1: a conditional exact fix.
- Rule 2: no step that only opens or finds.
- Rule 3: no work handed back.
- Rule 6: a time estimate only when it helps the reader plan.

## Version 1.1.0, 2026-11-19

- Rule 1: "or the result", the clarifying question, the copy targets.
- Rule 3: no next action when nothing is open.
- Rule 7: "with a way to try it".
- Rule 8: a cause needs evidence, and no secret value in a diagnostic check.
- Rule 9: the cap shapes presentation only.
- A numbered list starts at 2 steps.
- "normal mode" is the only off-phrase.
- The Good examples are whole sentences.
- Scope: labels, names, text for programs, token saving, other languages.
